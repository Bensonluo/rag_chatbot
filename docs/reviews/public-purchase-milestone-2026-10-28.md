# 公共访客与模拟购买里程碑

日期：2026-10-28。状态：本地实现、验证及归档完成；按用户要求停止后续迭代。当前工作区保留未提交改动。

## 交付范围

公共网站使用服务器签发的 HttpOnly Cookie 识别访客浏览器，无需注册；会话和购买记录按访客隔离。工作台保留。聊天已串起模拟商品检索、规格与数量、购物车、报价、显式确认下单、独立模拟付款与状态查询。

框架由 Agent、持久购买状态机和 CommercePort 组成。外部能力目前由独立事务 SQL mock 实现；模型不持有下单确认或付款工具。购买状态独立于聊天记录，清空聊天不撤销交易。订单和付款的未知结果通过原购买查询恢复。

本里程碑另修复两处可靠性问题：购物任务先持久切换任务状态，防止模型异常或请求取消后旧退款确认被继续；购买请求等待最多 30 秒，超时后解锁界面并要求明确查询状态，不自动重发。

## 后续边界

这仍是模拟交易；真实供应商接口、支付认证、生产 HTTPS Cookie 与 PostgreSQL 并发需要单独接入和验收。消息历史独立读取失败仍可能降级为空，聊天记录保存失败时购物卡恢复提示尚可改进；这些问题已记录为后续工作，本里程碑后不继续迭代。

两仓代码均保留当前未提交工作，本里程碑没有提交、推送或部署。完整框架合同见[公共购买合同](../design/public-commerce.md)，上一轮浏览器旅程见[购买链路证据](public-commerce-results-2026-10-28.json)。
